# 📱 Como Usar a Interface Web - Passo a Passo

## Início Rápido (30 segundos)

### Passo 1: Iniciar o Servidor

Abra o terminal e execute:

```bash
streamlit run app.py
```

Ou use o script automático:

```bash
./run_web.sh
```

### Passo 2: Acessar no Navegador

O navegador abrirá automaticamente em:
```
http://localhost:8501
```

Se não abrir, copie e cole esse endereço no navegador.

## 📱 Usar no Celular

### 1. Conecte-se à mesma rede WiFi

Seu computador e celular devem estar na mesma rede.

### 2. Veja o endereço no terminal

Quando iniciar o Streamlit, você verá algo como:

```
Network URL: http://192.168.1.100:8501
```

### 3. Acesse no navegador do celular

Digite o endereço "Network URL" no navegador do seu celular.

### 4. Use normalmente!

A interface se adapta automaticamente para telas pequenas.

## ❓ Problemas Comuns

### "Preencha todos os campos obrigatórios"

**Causa:** Algum campo obrigatório está vazio

**Solução:** Certifique-se de ter:
- ✓ Logo enviado
- ✓ Foto do produto enviada
- ✓ Nome da loja preenchido
- ✓ Nome do produto preenchido

### "Erro ao gerar criativos"

**Causa:** Problema com as imagens ou dados

**Solução:**
1. Verifique o formato das imagens (PNG, JPG)
2. Tente imagens menores (< 5MB)
3. Recarregue a página (F5)

### Página não carrega

**Causa:** Servidor não está rodando

**Solução:**
1. Verifique se executou `streamlit run app.py`
2. Aguarde até ver "You can now view your Streamlit app"
3. Tente reabrir o navegador

## 💡 Dicas para Melhores Resultados

### Para o Logo:
- ✓ Use PNG com fundo transparente
- ✓ Resolução mínima: 400x400px
- ✓ Formato quadrado ou horizontal

### Para o Produto:
- ✓ Imagem de alta qualidade
- ✓ Fundo limpo (branco de preferência)
- ✓ Produto bem iluminado
- ✓ Resolução mínima: 800x800px

### Para a Descrição:
- ✓ Seja conciso (60 caracteres)
- ✓ Destaque o benefício principal
- ✓ Use palavras que vendem

### Para as Cores:
- ✓ Use cores da identidade visual
- ✓ Escolha cores que contrastem
- ✓ Teste diferentes combinações

## 📊 Entendendo os Resultados

### Variação 1 (Minimalista)
- Background claro/neutro
- Produto centralizado
- Muito espaço em branco
- Design clean e profissional

### Variação 2 (Vibrante)
- Background com cores da marca
- Layout dinâmico
- Mais elementos visuais
- Impacto visual forte

**Dica:** Use a Variação 1 para públicos conservadores e Variação 2 para públicos jovens!
